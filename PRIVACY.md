# Privacy Policy: Localhost Tab Titles

Localhost Tab Titles does not collect, store, or transmit any personal data.

- The extension runs only on `localhost`, `127.0.0.1`, and `0.0.0.0` pages, and only changes
  the page title.
- It reads the page's port number and sends it to the optional helper at
  `http://127.0.0.1:47123`, which runs on your own computer. Nothing is sent anywhere else.
- The helper replies with a folder name and git branch, read from your local machine. Nothing
  is logged or saved.
- There are no analytics, no tracking, and no remote servers.

Questions: open an issue on the GitHub repository.
